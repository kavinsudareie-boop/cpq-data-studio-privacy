Oracle CPQ Data Studio (Chrome / Edge extension)
Last updated: 29 September 2026
Developer contact: kavinsudareie@gmail.com

Overview

Oracle CPQ Data Studio is a browser extension that adds a developer workbench on Oracle CPQ sites (*.bigmachines.com and *.oraclecloud.com). It uses the user’s existing logged-in CPQ browser session. It does not create a separate account system and does not send CPQ data to the developer’s own servers.

Data we process

  • CPQ session content: When you use the workbench, the extension calls Oracle CPQ REST APIs on the same site you are already visiting (for example quotes, lines, history, data tables, BML, and Commerce actions) and displays the responses in the UI.
  • Local preferences: Settings such as theme, process/document variables, read-only mode, recent quote IDs, optional compare snapshots, and saved REST requests may be stored in chrome.storage.local on your device.
  • Exports: If you export JSON/CSV or copy data, files stay on your device unless you choose to share them.

Data we do not collect

  • We do not sell user data.
  • We do not use extension data for advertising.
  • We do not collect passwords; authentication uses your existing CPQ login cookies in the browser.
  • We do not transfer CPQ data to third parties for creditworthiness or lending decisions.

Permissions

The extension requests activeTab, scripting, storage, and host access only to *.bigmachines.com and *.oraclecloud.com so it can inject the workbench and call CPQ APIs on those sites.
